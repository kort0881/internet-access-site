Setup guide

🔌 How to connect in 4 steps

Connecting to “Internet Access” (the @vlessbots_bot Telegram bot) takes about two minutes: copy the key from the bot, install an app, import the key, and tap “Connect”. The first 2 days are free so you can test speed and reliability.

Step 1. Copy the key in the bot

Open @vlessbots_bot, tap “My keys” — keys arrive in blocks. Under the message tap “Copy 1” (or 2, 3 — different channels). The bot sends the key as a separate message — tap it and it is copied.

Step 2. Install an app

  • Happ — iPhone, Android, Windows (happ.su)
  • Karing — Windows, Android, iOS (karing.app)
  • v2rayNG — Android (GitHub)
  • Hiddify — all platforms (hiddify.com)
  • Streisand — iPhone, iPad (App Store)

Step 3. Paste the key

Open the app, tap “Add configuration” (or “+”), choose “Import from clipboard”. The app detects the copied link and offers to add it. If there is no import button — use “Add from link” and paste the key manually.

Step 4. Connect

Tap the big connect button. You will see “Connected” — traffic now goes through “Internet Access” private servers. If it does not connect, see the section below.

Which key to choose

  • First — primary, works for most users.
  • Second — backup: try it if the first one fails.
  • Third (XHTTP) — for mobile networks when regular keys fail.

2-day free trial

Access is currently free for 2 days so you can verify it works for you. If speed and stability are fine, tap “RENEW” in the bot to get a private VLESS Reality / Hysteria2 / Trojan subscription.

If it does not work

  • Switch between Wi-Fi and mobile data.
  • Try another key from the list.
  • In the app tap “Update subscription” and reconnect.
  • Make sure battery/data saver is disabled for the app.
  • Still stuck — open the bot and use the “Support” section.

Important: your key is personal

The key is a personal link. Do not post it in chats or share it with others: third parties could use your subscription, which reduces speed and may lead to the key being blocked.
